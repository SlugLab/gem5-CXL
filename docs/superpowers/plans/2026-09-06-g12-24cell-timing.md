# G12 24-Cell Host and CIRA Timing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an independent, fail-closed G12 pipeline that prepares six-workload inputs, measures host-inline and CIRA time across four CXL latencies, survives logout/reboot at stage boundaries, and publishes 24 auditable timing/speedup rows.

**Architecture:** Add G12-specific preparation, execution, and publication entry points by porting the accepted G14 implementations without changing them. Bind a canonical G12 input manifest and prepared registry to frozen graph/CSR hashes, qualify both graph workloads at 200 ns, then run the fresh 48-stage matrix under a persistent systemd service.

**Tech Stack:** Python 3.13 standard library, `unittest`, canonical JSON and SHA-256, gem5 X86 TimingSimpleCPU, CIRA matched replay, exact `Decimal`, systemd, CSV.

```python
def _validate_g12_inputs(graph_path, graph_sha256, graph_manifest, csr_root):
    graph_path = Path(graph_path).resolve()
    if graph_sha256 != G12_SHA256 or sha256_file(graph_path) != G12_SHA256:
        raise RegistryError("G12 graph identity differs")
    manifest_path = _validate_file_record(graph_manifest, "G12 graph manifest")
    manifest = _load_json(manifest_path, "G12 graph manifest")
    if (
        manifest.get("scale") != 12
        or manifest.get("num_nodes") != G12_NODES
        or manifest.get("directed_edges") != G12_DIRECTED_EDGES
        or manifest.get("graph_sha256") != G12_SHA256
    ):
        raise RegistryError("G12 graph manifest identity differs")
    csr_root = Path(csr_root).resolve()
    for name, expected in G12_CSR_SHA256.items():
        if sha256_file(csr_root / name) != expected:
            raise RegistryError(f"G12 CSR {name} SHA-256 differs")
    meta = _load_json(csr_root / "graph.meta.json", "G12 CSR metadata")
    if (
        meta.get("graph_sha256") != G12_SHA256
        or meta.get("num_nodes") != G12_NODES
        or meta.get("num_directed_edges") != G12_DIRECTED_EDGES
    ):
        raise RegistryError("G12 CSR identity differs")
    return graph_path, csr_root
```
